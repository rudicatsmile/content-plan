# Panduan Pengguna (User Guide) - Content Plan App

Selamat datang di Aplikasi Content Plan. Dokumen ini adalah panduan cepat untuk menggunakan aplikasi sesuai dengan peranan (Role) Anda.

## 1. Lembaga Admin (Pembuat Konten)
Sebagai Admin Lembaga, tugas utama Anda adalah mengajukan draf konten untuk disetujui sebelum dipublikasi.

- **Login**: Gunakan kredensial lembaga Anda.
- **Melihat Kalender**: Setelah login, Anda akan diarahkan ke *Dashboard* Kalender. Di sini Anda bisa memantau jadwal konten khusus untuk lembaga Anda sendiri.
- **Mengajukan Konten Baru**:
  1. Klik tombol **"+ Ajukan Konten"** pada *Dashboard*.
  2. Isi Judul, Deskripsi, dan unggah draf Gambar jika ada.
  3. Pilih tanggal rencana unggah, lalu tandai platform sosial media yang akan dituju.
  4. Klik **Submit**. Status pengajuan Anda kini adalah `draft` atau `pending_review`.
- **Melihat Notifikasi**: Tiap kali pengajuan Anda disetujui (Approve) atau ditolak (Reject), sebuah *pop-up* dan notifikasi di lonceng pojok kanan atas akan otomatis muncul.

## 2. Media Admin (Penyetuju Konten)
Sebagai Admin Media Pusat, tugas Anda adalah meninjau seluruh konten yang masuk dari berbagai Lembaga.

- **Memantau Pengajuan**: 
  - Buka **Dashboard** (Kalender) untuk melihat seluruh jadwal dari semua lembaga. Anda dapat memfilternya di *Sidebar*.
  - Kotak kuning menandakan konten belum disetujui (Menunggu Review).
- **Memberikan Persetujuan (Approve/Reject)**:
  1. Anda bisa mengeklik langsung *event* berwarna kuning di kalender, ATAU masuk ke menu **Semua Pengajuan**.
  2. Baca detail konten yang diajukan.
  3. Tulis catatan evaluasi (misal: "Visual sudah bagus, silakan post").
  4. Klik **Setujui** (Approve) atau **Tolak/Revisi** (Reject).
  5. Pengunggah secara otomatis akan mendapat notifikasi dan warna jadwal di kalender berubah menjadi Hijau (jika Setuju) atau Merah (jika Ditolak).

## 3. Pimpinan (Pemantau)
Sebagai Pimpinan, peran Anda adalah memonitor secara makro dan memastikan alur konten berjalan lancar.

- Anda memiliki hak akses penuh ke **Dashboard Kalender** seluruh lembaga layaknya Media Admin.
- Anda dapat menyaring data berdasar lembaga tertentu atau *platform* (misal: hanya melihat jadwal untuk Instagram).
- Anda juga akan menerima notifikasi setiap kali ada konten yang disetujui, sehingga Anda selalu *up-to-date* dengan publikasi terbaru.
